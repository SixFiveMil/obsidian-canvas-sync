Privacy Policy & Transparency

Canvas to Obsidian Sync

Effective Date: September 5, 2026 • Last Updated: September 5, 2026
Publisher: Joshua (@SixFiveMil) • Project: github.com/SixFiveMil/obsidian-canvas-sync

Core Guarantee: Canvas to Obsidian Sync is a 100% local-first, privacy-respecting utility. We run no remote cloud servers, collect no telemetry or analytics, and store no personal data. Course materials are transmitted strictly over a secure local loopback connection (127.0.0.1) directly to your Obsidian desktop application.

1. Introduction & Single Purpose

Canvas to Obsidian Sync is a companion browser extension designed for students, researchers, and educators who use Obsidian for academic knowledge management. The single, dedicated purpose of the extension is to extract academic course materials (modules, syllabus documents, assignments, rubrics, announcements, discussion prompts, and pacing tables) from an active Canvas LMS session and securely deliver them as clean GitHub Flavored Markdown (GFM) notes to the user's personal Obsidian vault.

2. Information Handled by the Extension

To fulfill its single purpose, the extension processes the following data categories strictly on your local machine:

A. Academic Course Content

  • Data Handled: Course title, course code, module names, page texts, assignment prompts, rubrics, discussions, syllabus text, and pacing guide tables.
  • Processing: Upon user click ("Sync Active Course"), the extension parses the DOM of your active Canvas course tab, converts the elements into structured Markdown, and temporarily holds the payload in browser memory.
  • Transmission: The Markdown payload is sent directly via local HTTP POST to http://127.0.0.1:27125 (or your custom configured loopback port).
  • Storage: The local Obsidian plugin writes the received Markdown directly to your local file system vault. The browser extension does not store course contents.

B. Session Credentials & Authentication

  • The extension operates strictly through your existing logged-in browser session with your institution's Canvas LMS.
  • The extension never intercepts, records, logs, or transmits your Canvas passwords, login credentials, session cookies, or multi-factor authentication tokens.
  • If you choose to input a Canvas personal access token for restricted school environments, the token is saved strictly in your browser's private local storage (chrome.storage.local) and is only sent directly to your institution's official Canvas domain.

C. Local Settings & Preferences

  • Configuration choices (such as local bridge port, folder naming templates, and timestamp of the last sync) are saved locally using Chrome's chrome.storage.local API on your machine.

3. Information We Do NOT Collect

We do not collect, track, or share any user data. Specifically, we do NOT collect:

  • Personal identification information (name, email address, physical address, student ID).
  • Web browsing history, navigation habits, or search history.
  • IP addresses, geolocation coordinates, or network telemetry.
  • Financial, credit, or payment details.
  • Academic evaluation metrics, grades, or submitted coursework without explicit user sync invocation.
  • Tracking pixels, advertising IDs, or telemetry SDKs (e.g., Google Analytics, Segment, Sentry).

4. Chrome Extension Permissions & Technical Justifications

Every permission requested in manifest.json is strictly tied to the extension's core functionality:

Permission Technical Justification
activeTab Grants temporary access to the active browser tab only when you click the extension popup to inspect or extract course content from Canvas LMS. Requires no broad website access.
scripting Allows the extension to inject extraction scripts into the active Canvas tab to parse the course DOM, retrieve module items, and format pacing tables.
storage Stores local configuration settings (e.g., bridge port number, folder naming templates) within your browser's private local storage.
optional_host_permissions
http://127.0.0.1/*
http://localhost/*		 Requested upon user action ("Test Bridge" or "Sync Active Course") to permit HTTP POST requests across the loopback network to the local Obsidian bridge server running on your device. Zero install-time host warnings.

5. Compliance with Chrome Web Store Limited Use Requirements

Canvas to Obsidian Sync complies fully with the Chrome Web Store User Data Policy, including the Limited Use requirements:

  • No Sale of Data: User data is never sold, leased, or traded to third parties, advertising networks, or data brokers.
  • No Unrelated Data Transfers: User data is never transferred or used for any purpose other than providing and enhancing the single core function of the extension.
  • No Targeted Advertising: User data is never used or transferred for personalized advertising, retargeting, or promotional profiling.
  • No Creditworthiness Assessment: User data is never used or transferred to determine creditworthiness or for financial lending purposes.

6. Security and Local Loopback Isolation

All communication between the browser extension and Obsidian occurs solely across the host machine's loopback interface (127.0.0.1). No data leaves your personal computer during the sync process. Requests to the bridge include custom verification headers (X-Canvas-Sync-Client) to protect against unauthorized cross-origin calls.

7. User Rights, Data Ownership & Deletion

You retain 100% ownership and control over your data. All exported coursework notes reside as plain Markdown files on your local drive within your Obsidian vault. You may edit, relocate, or delete them at any time.

To erase all stored preferences in the browser extension, simply remove the extension via chrome://extensions or clear site data for the extension.

8. Children's Online Privacy Protection Act (COPPA)

Canvas to Obsidian Sync does not knowingly collect or solicit personal information from children under the age of 13. The extension is an educational utility that requires neither account registration nor remote data storage.
